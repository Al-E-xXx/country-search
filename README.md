# country-search

Страница поиска стран по названию. Данные: [Countries API](https://countries.dev/).

## Запуск

Нужен Node.js 20 или новее.

```bash
npm ci
npm run build
npm start
```

Открыть <http://localhost:3000>.

## Проверка

```bash
npm test
npm run lint
```

Документация по решению: [DESIGN.md](./DESIGN.md).
